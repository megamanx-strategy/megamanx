# ここに書かれているのは何？

基本は、スーパーファミコン用ゲームソフト・ロックマンXの解析結果を書いておこうと思っています。<br>
主にRTA走者の役に立てば良いと思って書いていますが、それ以外のロックマンXに関心がある方々の役にも立てるかと思います。<br>
ボスキャラクターの行動AIについての記載がほとんどになると思います。<br>
解析の多くは、手動でなく、AIが行いました。<br>
AIによる情報なので、誤りも含まれている可能性があることをご承知ください。<br>
時間が掛かるかもしれませんが、できるだけその内容を確認して、本当に正しいのかを判断していきたいと思っています。<br>
AIが書いた攻略方法も併記されています。<br>
その文章に対して私が手動で修正を行った部分もあります。<br>
この二つが混ざっているので、その点も今後改善していこうと思っている点です。
