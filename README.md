# ここに書かれているのは何？

基本は、スーパーファミコン用ゲームソフト・ロックマンXの解析結果を書いておこうと思っています。<br>
主にRTA走者の役に立てば良いと思って書いていますが、それ以外のロックマンXに関心がある方々の役にも立てるかと思います。<br>
ボスキャラクターの行動AIについての記載がほとんどになると思います。<

|ゲームソフトタイトル|ロックマンX|
|:---:|:---:|
|ゲームハード|スーパーファミコン|
|解析に使用した、ゲームソフトの言語バージョン|日本語|
|解析に使用した、ゲームソフトのバージョン|1.0|

ゲームソフトの言語とバージョンは上記の通りですが、ロックマンXであれば、別の言語やバージョンであっても、記事内のデータと同様である内容がほとんどでのはずです。
